## **🌐 Admission Form - Study MBBS Abroad**

🚀 A fully responsive admission form for students applying to study MBBS abroad. Built with **HTML, CSS, and JavaScript**, and powered by **Node.js & Express.js** on the backend with **MongoDB** for database storage.

---

### **📌 Features**
✅ Beautiful **blue gradient UI** for a modern look  
✅ Fully **responsive design** for all devices  
✅ **Form validation** for name, email, and phone number  
✅ **MongoDB database** to store form submissions  
✅ **Deployed on Vercel & Netlify**  


---

### **🚀 Live Demo**
🔗 **Frontend (Vercel):** [https://university-insights-sandy.vercel.app/](#)

### **🛠️ Tech Stack**
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Atlas)  
- **Deployment:** Netlify, Vercel

### **📝 Setup Instructions**
Follow these steps to run the project locally.

#### **1️⃣ Clone the Repository**
```bash
git clone https://github.com/radhika-khatter/UniversityInsights.git
cd UniversityInsights
```

#### **2️⃣ Install Dependencies**
Navigate to the backend folder and install dependencies:
```bash
cd backend
npm install
```

#### **3️⃣ Setup Environment Variables**
Create a `.env` file in the `backend` directory and add:
```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

#### **4️⃣ Run the Backend Server**
```bash
npm start
```
Backend should now be running on **http://localhost:5000**

#### **5️⃣ Open the Frontend**
Simply open `index.html` in your browser.

---

### **🚀 Deployment**
- **Frontend (Vercel):**
  - Upload the `frontend` folder to Vercel.

  - Run:
